# 同人角色扮演设计skill

用于创建、修改 SillyTavern 同人世界书，并将角色与相关内容融入已有世界书 JSON。

## 两种模式

使用时先选择一种模式：

- **还原模式**：整理原作世界背景、叙事气质、主线剧情、人物及重要地点；人物资料可随主线阶段变化。
- **人物模式**：重点描写外貌、性格、表达、行为与关系，并依据原作补充必要设定；先选择角色范围，再决定是否创建主要场景。

## MVU 与融合规则

- 独立新建还原模式世界书时，由用户选择是否使用 MVU；选择后提供完整变量配套，通过一个主线阶段变量与 EJS 控制相关资料开放。
- 主线阶段控制仅适用于采用 MVU 的还原模式。独立人物模式采用普通文本人物条目及可选场景。
- 融合已有 JSON 时，先识别其是否采用 MVU。采用时适配现有变量；未采用时使用普通文本，不添加 MVU 或 EJS。
- 新角色参照目标已有角色条目的内容结构、必要字段和初始设定进行编写。
- 适配可能偏离原作时，先由用户选择允许目标世界观改编，或保持原作设定。
- 已有角色具备 MVU 变量时，为新角色配置对应变量，并扩充已有初始化、更新规则和输出格式等配套。
- MVU 修改前查阅配套参考中的教程；默认相关依赖已准备就绪，环境帮助按用户要求提供。

## 内容原则

- 联网收集原作资料，保持作品版本与人物身份一致。
- 人物描写以人物特点为依据，基础维度可按原作需要扩展。
- 参考来源与研究笔记保存在世界书之外。
- 用户身份及入场设计仅在用户明确要求时处理。
- 融合结果默认另存为完整 JSON，保留原文件及无关内容。

## 安装

1. 下载并解压本仓库。
2. 将包含 `SKILL.md` 的整个目录放入所使用工具的 `skills` 目录。
3. 将该目录命名为 `fanfic-roleplay-design`，保留其中的 `references` 与 `agents` 等配套内容。

## 调用

在支持此调用方式的工具中输入 `$fanfic-roleplay-design`，再提供作品名称、版本和制作需求。需要融合时，同时提供目标世界书 JSON。

入口文件为 [SKILL.md](SKILL.md)，模式规则及 MVU 指南位于 [references](references/)。
